Cap Technique

Objectifs Clés du Projet

SIMPLON MAGHREB

Sécuriser l'API Backend

Protéger l'intégralité des routes REST sensibles contre les requêtes non autorisées avec Spring Security.

Authentifier via JWT

Délivrer et vérifier des jetons cryptographiques signés lors du Login pour un mode sans état.

Gérer les Rôles (RBAC)

Restreindre les accès métier selon le rôle attribué à l'utilisateur (ADMIN, MANAGER, AGENT).

Développer l'Interface React

Créer une SPA ergonomique, fluide et réactive avec React 19, Vite et Material UI.

Connecter le Frontend à l'API

Automatiser l'envoi du jeton JWT via des intercepteurs Axios et sécuriser la gestion des erreurs HTTP (401/403).

Sécurité Client

Sécurité & Routage React

SIMPLON MAGHREB

Intercepteurs Axios

1. Request Interceptor : Injecte le header Authorization: Bearer <token> dans chaque requête HTTP sortante.


2. Response Interceptor : Intercepte automatiquement les erreurs 401 Unauthorized pour réinitialiser la session (Logout) et rediriger vers la page Login.

ProtectedRoute

Composant de garde vérifiant la présence d'une session valide avant d'autoriser l'accès aux routes privées.

RoleGuard

Composant de contrôle fin masquant ou restreignant l'accès aux éléments d'interface selon le rôle de l'utilisateur (ADMIN/MANAGER/AGENT).
